# Annotate actual source evidence

Read current source text and existing annotations. Select the passages needed by the requested sections,
then bind the selected passage and revision with add_annotation. For the entire passage, omit both
start and end. For a partial quote, supply both zero-based character offsets with an exclusive end.
Choose sources and passages yourself; this tool does not decide relevance. A read-status claim is not a
quote. Reuse an existing annotation only when its canonical ownership and entire source passage remain
current; a changed passage invalidates an old annotation even when the quoted prefix happens to match.
Unchanged passages may be reused across revisions. Keep old annotations as history and create replacement
evidence where needed. Inspect returned content and retain annotation IDs for review and citation skills.
