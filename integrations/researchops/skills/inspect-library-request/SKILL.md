# Inspect a living-library request

Read the task's section criteria and acquired-round workspace. Identify the next acquisition and, when
advancing, inspect the prior review artifact that will become immutable acquisition history. Acquisition
does not certify that this review is correct. Search actual catalog metadata with pagination, then read
source records and text for candidates. Do not treat a paper ID, title similarity or pdf_stored as evidence
of publication identity, relevance or a document's contents. Historical metadata-only PDFs have no text
artifact in this environment. Record the batch and source identities used by subsequent skills.
