# Maintain source-backed citation contexts

Read actual reference passages and canonical target records. Create exact source annotations and connect
them to the publication actually identified in the passage. Each distinct source context matters even
when endpoint pairs are equal. Reuse current existing contexts; retire obsolete active evidence rather
than deleting history. Inspect the directed network after merges, including archived same-work references.
Do not substitute an equal-count target or invent context text. Pass actual citation IDs to later review
assembly, along with their citing-paper and annotation ownership.
