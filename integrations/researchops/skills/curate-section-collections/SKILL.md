# Curate section collections

For each requested section, compare actual canonical source metadata with the declared year, study-type
and topic criteria. Include every acquired matching work exactly once. Read current collection and reading
list memberships before adding or retiring relationships; maintain the corresponding topic tag. A valid
irrelevant paper can be added by the tool, so successful insertion is not proof of a correct selection.
Reconcile repeated ownership after identity merges and preserve historical retired links. Different legal
reading orders are allowed. Retain the selected canonical work set for bibliography and review assembly.

## Coverage and overlap

Use the current source metadata, not titles, record order or the results payload's role,
to apply each section's criteria. Evaluate a work against every section independently.
A matching work belongs in that section's collection, reading list, tag and review even
when it is excluded from numerical pooling. Metadata study_type and results role are
different fields. Global statistical deduplication never removes valid section membership.
