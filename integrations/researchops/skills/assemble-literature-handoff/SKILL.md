# Assemble a literature handoff

Join each section's selected canonical works, current full results annotations, actual outgoing reference
contexts and the current bibliography's exact citation keys. Compose the review and read its real Markdown
artifact. Verify section coverage, work identity, quoted text and inline citations against the preceding
skill outputs. The composition tool validates references, not completeness or relevance; an empty or
incomplete section can render successfully. Correct omissions before committing a review to the next
acquisition. Preserve prior exports and their original evidence after later source corrections.

Check coverage against the public section criteria, not only the list retained from an
earlier skill. A work matching several sections needs evidence in every matching section.
When quantitative synthesis is enabled, review coverage includes both contributions
and exclusions; excluding a work from the numerical denominator does not remove it
from the review. Submission receipts confirm storage, not completion of these checks.
