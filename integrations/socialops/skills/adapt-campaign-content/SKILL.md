# Adapt Campaign Content

Compute the consenting audience intersection from all parent winners and the brief's allowed audiences.
Submit it through bind_campaign_learning together with the exact reports and highest-rate parent when
several reports join. The tool validates your calculation; it does not supply a corrected intersection.
For the first wave, submit an empty report set and that variant's declared initial audiences.

Edit the actual post body to include the brief's product fact, disclosure and assigned CTA. Carry every
parent winner CTA into the text. Additional natural prose is allowed within the account length limit.
Choose only ready eligible assets with valid rights and preserve the correct campaign/account identity.

For a deployment, bind the current brief's completed report and copy its winning body/assets/audiences.
This is deployment of measured content, not another unmeasured alternative. An edit or changed learning
binding invalidates prior approval and releases any future reservation. Published history is immutable.

Outputs: edited post IDs/versions and actual learning references. Do not self-declare approval.
