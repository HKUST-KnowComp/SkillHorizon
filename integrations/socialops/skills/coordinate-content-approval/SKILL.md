# Coordinate Content Approval

Submit the current post using the task's coordinator identity, declared reviewer and final_approval
stage. Run the environment review and inspect the resulting rule checks and actual decision. These
are deterministic structural checks, not human judgments about marketing quality.

If rejected, inspect the facts, asset status, audience and historical learning that caused the failure.
Repair the real post, then request a fresh review. Previous content versions and canceled requests are
historical evidence only. The coordinator cannot impersonate the reviewer or manufacture metrics.

Outputs: actual approval request, content version and decision. A skill finish does not grant approval.
